About this site

An unofficial learning site for Hypercore. It is not affiliated with Holepunch, the authors of Hypercore.

What is checked, and how

  • Code. Every example runs against the pinned hypercore version before the site is published, and the output printed under it is the output of that run. node scripts/check.mjs fails if an example errors or prints something else.
  • Names. Every method, property and static value on the API page is looked up on a real core by the same script.
  • Links. The script fails on any internal link that points nowhere, on any external font or script request, and on a short list of phrases the first review of this site turned up.
  • Claims. Statements about what Hypercore does come from the upstream README, from the installed package source, or from a run. Where the site says "the README says", it has not tested that claim.

What is not covered

The ecosystem modules (Hyperswarm, Corestore, Hyperbee, Hyperdrive, Autobase), networking across machines, performance and the wire protocol. Atoms are described in the README but not run here. The home page demo is a simulation of the tree: it uses SHA-256 so it can run in a browser, where Hypercore uses BLAKE2b.
