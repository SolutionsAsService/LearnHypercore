API reference

A short reference: . A script creates a real core and checks that every method, property and static value named here exists. Events and descriptions are paraphrased from the README and are not checked by the script. For options and details, the full reference is in the Pears documentation and the README.

Constructor: new Hypercore(storage, [key], [options]). storage is a directory path. key is the public key of a core you want to read. Options include valueEncoding ('json', 'utf-8' or 'binary', default binary), createIfMissing, overwrite, encryption and timeout.
