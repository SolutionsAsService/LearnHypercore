Learn Hypercore

Hypercore is a secure, distributed append-only log. Add blocks below and watch the tree that lets anyone verify them.

A simulation. Fingerprints here are SHA-256 so they run in a browser. Hypercore hashes with BLAKE2b and signs the hash of the roots with the core's key pair. Source

    In one line each: a block is one entry in the log; a hash is a short fingerprint of data; a root is the fingerprint of a whole branch; a peer is another copy of the log.
