Get started

Install it, run one file, read what it printed.

What you need

Node.js (download it from nodejs.org; it comes with npm) and a terminal. The examples here were run on Node see data/verified.json. Check yours with node --version. If you cannot install anything, the interactive tree on the home page runs in your browser and teaches the same idea.

1. Install

mkdir my-core && cd my-core
npm init -y
npm install hypercore

If your shell rejects &&, run those two commands one at a time.

The examples on this site were run on Node with hypercore see data/verified.json. The README at that version still says the latest release is Hypercore 10, while the npm latest tag is 11, so check the version you installed with npm ls hypercore.

2. Run your first core

Save this as hello.js and run node hello.js. The grey-green box shows what it printed when we ran it.

3. What just happened

  • new Hypercore('./hello-core') stores the core in the directory hello-core. Run the file again and the length grows, because the data is still there.
  • valueEncoding: 'utf-8' makes get return strings. Without it you get Buffers, which is the default.
  • Passing an array to append adds several blocks as a batch.

If an older tutorial's code fails

Older examples create a core with an in-memory storage function, new Hypercore(() => new RAM()), using random-access-memory. The upstream README says random-access-storage is no longer supported, and that code crashes on version 11. Pass a directory path instead.
